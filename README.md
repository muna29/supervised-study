# AI Battle Arena

A single-file React app (no build tools required). Perfect for GitHub Pages.

## Run locally
Just open `index.html` in your browser.

## Deploy to GitHub Pages
1. Create a new repository on GitHub (e.g., `ai-battle-arena`).
2. Upload `index.html` to the repo root (literally drag & drop).
3. In **Settings → Pages**, set:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` (or `master`) / root
4. Wait a minute; your site will be live at the Pages URL.

## Dev notes
- Uses React 18 UMD + Babel Standalone + Tailwind Play CDN.
- No bundler. If you want a Vite project, I can generate one too.
